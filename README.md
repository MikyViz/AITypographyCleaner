# AI Typography Cleaner

Браузерное расширение (Manifest V3, Chrome + Firefox), которое заменяет типографские
спецсимволы ИИ-текста (кавычки-«ёлочки», тире, многоточия, спецпробелы, невидимые
символы и т.п.) на обычные клавиатурные аналоги — так, будто текст напечатан вручную.

## Структура проекта

```
manifest.json          — манифест MV3 (шаблон; background переписывается сборщиком под таргет)
src/core/rules.ts       — чистые regex-примитивы для каждой группы правил
src/core/normalize.ts   — normalize(text, opts): чистая функция без побочных эффектов
src/shared/settings.ts  — чтение/запись browser.storage.sync, whitelist-хелперы
src/shared/theme.ts     — тип Theme и applyTheme() — форсирует data-theme на <html> для Light/Dark
_locales/               — переводы интерфейса WebExtension (по языку браузера; английский — fallback)
src/assets/48.png       — иконка расширения 48 × 48
src/assets/128.png      — иконка расширения 128 × 128
src/shared/messages.ts  — типы сообщений content ⇄ background
src/content.ts          — перехват copy/paste на whitelist-сайтах + обработчик контекстного меню
src/background.ts       — фоновый скрипт: контекстное меню, permissions, регистрация content script
src/popup/              — popup с textarea "вставил → очистил → скопировал"
src/options/            — страница настроек (чекбоксы правил + whitelist доменов)
tests/normalize.test.ts — vitest, минимум 1 кейс на каждое правило
scripts/build.mjs       — esbuild-бандлер, собирает под --target=chrome|firefox
```

Вся работа с WebExtension API идёт через [`webextension-polyfill`](https://github.com/mozilla/webextension-polyfill)
(`browser.*` с промисами) — это снимает главный источник несовместимости с Chrome (`chrome.*`
в Firefox не всегда возвращает Promise без колбэка).

## Сборка

```bash
npm install
npm run build          # dist/ — production-бандл под Chrome/Chromium
npm run build:firefox  # dist-firefox/ — production-бандл под Firefox
npm run build:all      # оба сразу
npm run watch          # пересборка dist/ при изменениях (Chrome)
npm run watch:firefox  # пересборка dist-firefox/ при изменениях
npm test               # vitest — тесты ядра normalize()
npm run typecheck      # tsc --noEmit
```

Сборщик копирует иконки в `icons/` внутри каждой папки сборки. Единственное отличие
между таргетами — ключ `background` в манифесте
(`service_worker` для Chrome MV3 vs `scripts` для Firefox, который до сих пор не запускает
фон как настоящий Service Worker). Весь остальной код и permissions идентичны.

## Загрузка в браузер

### Chrome / Edge / Brave (Chromium)
1. `npm run build`.
2. Открыть `chrome://extensions`.
3. Включить "Режим разработчика" (Developer mode).
4. "Загрузить распакованное расширение" → выбрать папку `dist/`.

### Firefox
1. `npm run build:firefox`.
2. Открыть `about:debugging#/runtime/this-firefox`.
3. "Load Temporary Add-on…" → выбрать `dist-firefox/manifest.json`.

> Временная установка в Firefox живёт до перезапуска браузера. `browser_specific_settings.gecko.id`
> в манифесте уже задан, поэтому `storage.sync` работает стабильно между перезагрузками
> (без него Firefox генерирует новый ID аддона на каждую загрузку и storage.sync ломается).

> Собранные бандлы не запускались вживую в Firefox в рамках этой сессии (нет доступа к браузеру) —
> код и манифест написаны и типизированы под официально задокументированное поведение Firefox
> (WebExtensions `scripting`, `permissions`, `contextMenus`, `storage.sync`, `menus`), но перед
> публикацией стоит один раз вручную проверить через `about:debugging`.

## Как это работает

- **Копирование на whitelist-сайтах.** `content.ts` статически внедряется на
  `chatgpt.com`, `claude.ai`, `gemini.google.com` (заданы в `host_permissions`, без `<all_urls>`).
  По событию `copy` берётся выделенный `Range`, клонируется в offscreen-контейнер,
  текстовые ноды обходятся через `TreeWalker` и прогоняются через `normalize()`.
  Содержимое `<pre>` и `<code>` не трогается. В буфer кладутся сразу и `text/plain`,
  и очищенный `text/html`.
- **Контекстное меню.** "Очистить выделенное" (при наличии выделения) записывает
  очищенный текст в буфер через `navigator.clipboard.writeText` (permission `clipboardWrite`).
  "Вставить очищенным" (в полях ввода) читает буфер через `navigator.clipboard.readText()`
  и вставляет очищенный текст в фокусный элемент — это работает без отдельного
  permission `clipboardRead`, так как вызов происходит в контенте страницы в ответ
  на пользовательский клик по пункту меню. На страницах вне whitelist скрипт
  внедряется точечно через `activeTab`, разрешение не расширяется на весь интернет.
- **Popup.** Textarea → "Очистить" → `normalize()` с текущими настройками → "Копировать".
- **Options.** Чекбоксы включают/выключают каждую группу правил, whitelist редактируется
  (добавление домена запрашивает `browser.permissions.request` только на этот конкретный домен
  через `optional_host_permissions`, без запроса доступа ко всем сайтам сразу). Настройки хранятся
  в `browser.storage.sync`.
- **Тема оформления.** Селектор "Системная / Светлая / Тёмная" в настройках ([src/shared/theme.ts](src/shared/theme.ts)).
  "Системная" отдаёт управление CSS `prefers-color-scheme`; "Светлая"/"Тёмная" проставляют
  `data-theme` на `<html>` и форсируют тему независимо от ОС/браузера — это нужно, например,
  в Firefox, где настройка "Website appearance" не влияет на страницы расширений (`moz-extension://`),
  и тема там всегда следует системной, а не выбору пользователя на уровне контента.
- **Языки интерфейса.** В настройках есть селектор "Язык" ([src/shared/i18n.ts](src/shared/i18n.ts)):
  "Авто" определяет язык по языку браузера, либо можно выбрать язык вручную — выбор сохраняется
  в `browser.storage.sync` и применяется сразу, без перезагрузки popup/options. Английский
  используется как язык по умолчанию, если для выбранной локали нет перевода. Доступны английский,
  немецкий, французский, испанский, итальянский, португальский (Бразилия и Португалия),
  нидерландский, польский, русский, украинский, иврит, китайский (упрощённый и традиционный),
  японский, корейский и хинди. Иврит отображается справа налево. Заголовки контекстного меню
  (`background.ts`) тоже следуют этому выбору и обновляются сразу при смене языка в настройках.
  Название/описание расширения в списке расширений браузера (`manifest.json`, `_locales/`) — отдельный
  механизм WebExtension i18n, который Chrome/Firefox локализуют только по языку браузера на момент
  установки и не позволяют переключать из кода.

## Правила замены

Все включены по умолчанию (кроме "Смайликов" — см. ниже), каждая группа переключается отдельно в настройках.

| # | Группа | Примеры |
|---|--------|---------|
| 1 | Кавычки | `“ ” „ « »` → `"`; `‘ ’ ‚ ‹ ›` → `'` |
| 2 | Тире | `—`/`–` между словами → настраиваемый режим (`" - "` / `"-"` / `", "`); между цифрами всегда `-` (`5–10` → `5-10`) |
| 3 | Многоточие | `…` → `...` |
| 4 | Спецпробелы | `U+00A0`, `U+2002…U+200A`, `U+202F`, `U+205F`, `U+3000` → обычный пробел |
| 5 | Невидимые символы | `U+200B`, `U+2060`, `U+FEFF`, `U+00AD`, `U+200E`, `U+200F` удаляются. `U+200D` (ZWJ) и `U+FE0F` не трогаются никогда — нужны для составных эмодзи |
| 6 | Прочее | `−`(U+2212), `‑`(U+2011) → `-`; `•` → `-`; `→` → `->`; `←` → `<-`; `×` → `x` (только между буквой/цифрой с двух сторон, не в формулах с пробелами); `′` → `'`; `″` → `"` |
| 7 | Смайлики (эмодзи) | *Выключено по умолчанию.* Удаляет эмодзи целиком — включая ZWJ-последовательности (👨‍👩‍👧), тон кожи (👍🏽), флаги (🇺🇸) и keycap-эмодзи (3️⃣), а также символы вроде ©/®/™ |
| 8 | Схлопывание пробелов | Двойные пробелы, образовавшиеся после замен, схлопываются в один; отступы и переводы строк не трогаются |

**Не трогается:** иврит (`״` U+05F4, `׳` U+05F3, `־` U+05BE, огласовки), содержимое
`<pre>`/`<code>` (DOM-уровень) и URL/email-адреса (на уровне `normalize()` — они
определяются регэкспом и исключаются из всех замен).

## Как добавить своё правило

1. В [src/core/rules.ts](src/core/rules.ts) добавить regex/функцию по аналогии с существующими
   (`replaceQuotes`, `replaceMisc` и т.д.) — чистая функция `string → string`.
2. Подключить её в [src/core/normalize.ts](src/core/normalize.ts) внутри `normalize()`,
   добавив булев флаг в интерфейс `Options` и `defaultOptions`.
3. Добавить чекбокс в [src/options/options.html](src/options/options.html) и
   [src/options/options.ts](src/options/options.ts) (`checkboxIds` + `readOptionsFromForm`).
4. Добавить минимум один тест-кейс в [tests/normalize.test.ts](tests/normalize.test.ts).

## Известные допущения по умолчанию

- Угловые кавычки `« »` трактуются как двойные, одиночные угловые `‹ ›` — как одиночные
  (в ТЗ они упомянуты в обеих группах — вероятно, опечатка).
- `×` заменяется на `x` только когда вплотную примыкает к букве/цифре без пробелов
  (`1920×1080` → `1920x1080`), а `2 × 2` не трогается — это и есть эвристика "не в формулах".
- Сборка — esbuild (без UI-фреймворков, множественные точки входа собираются проще).
- Удаление смайликов выключено по умолчанию: это единственное правило, которое не просто
  нормализует типографику, а убирает видимый контент, поэтому решение оставлено за пользователем.
  Правило целиком удаляет emoji-последовательности (`Extended_Pictographic` + модификаторы тона
  кожи/ZWJ/variation selector-16), пары regional indicator (флаги) и keycap-эмодзи; заодно под
  него попадают символы вроде `©`/`®`/`™`, которые Unicode также относит к `Extended_Pictographic`.
