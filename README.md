# AI Typography Cleaner

Браузерное расширение (Manifest V3, Chrome + Firefox), которое заменяет типографские
спецсимволы ИИ-текста (кавычки-«ёлочки», тире, многоточия, спецпробелы, невидимые
символы и т.п.) на обычные клавиатурные аналоги — так, будто текст напечатан вручную.

## Структура проекта

```
manifest.json          — манифест MV3
src/core/rules.ts       — чистые regex-примитивы для каждой группы правил
src/core/normalize.ts   — normalize(text, opts): чистая функция без побочных эффектов
src/shared/settings.ts  — чтение/запись chrome.storage.sync, whitelist-хелперы
src/shared/messages.ts  — типы сообщений content ⇄ background
src/content.ts          — перехват copy/paste на whitelist-сайтах + обработчик контекстного меню
src/background.ts       — service worker: контекстное меню, permissions, регистрация content script
src/popup/              — popup с textarea "вставил → очистил → скопировал"
src/options/            — страница настроек (чекбоксы правил + whitelist доменов)
tests/normalize.test.ts — vitest, минимум 1 кейс на каждое правило
scripts/build.mjs       — esbuild-бандлер
```

## Сборка

```bash
npm install
npm run build      # собирает dist/ (production-бандл)
npm run watch       # то же самое, но пересобирает при изменениях
npm test            # vitest — тесты ядра normalize()
npm run typecheck   # tsc --noEmit
```

Результат сборки — папка `dist/`, готовая к загрузке как unpacked-расширение.

## Загрузка в браузер

### Chrome / Edge / Brave (Chromium)
1. `npm run build`.
2. Открыть `chrome://extensions`.
3. Включить "Режим разработчика" (Developer mode).
4. "Загрузить распакованное расширение" → выбрать папку `dist/`.

### Firefox
1. `npm run build`.
2. Открыть `about:debugging#/runtime/this-firefox`.
3. "Load Temporary Add-on…" → выбрать `dist/manifest.json`.

> Временная установка в Firefox живёт до перезапуска браузера. `browser_specific_settings.gecko.id`
> в манифесте уже задан, поэтому `storage.sync` работает стабильно между перезагрузками
> (без него Firefox генерирует новый ID аддона на каждую загрузку и storage.sync ломается).

> Примечание про MV3 в Firefox: `background.service_worker` поддерживается начиная с
> Firefox 109+. Если у вас более старая/ESR-сборка без этой поддержки, замените в
> `manifest.json` ключ `"background": { "service_worker": "background.js" }` на
> `"background": { "scripts": ["background.js"] }` — весь остальной код совместим с обоими вариантами.

## Как это работает

- **Копирование на whitelist-сайтах.** `content.ts` статически внедряется на
  `chatgpt.com`, `claude.ai`, `gemini.google.com` (заданы в `host_permissions`, без `<all_urls>`).
  По событию `copy` берётся выделенный `Range`, клонируется в offscreen-контейнер,
  текстовые ноды обходятся через `TreeWalker` и прогоняются через `normalize()`.
  Содержимое `<pre>` и `<code>` не трогается. В буфer кладутся сразу и `text/plain`,
  и очищенный `text/html`.
- **Контекстное меню.** "Очистить выделенное" (при наличии выделения) записывает
  очищенный текст в буфер через `navigator.clipboard.writeText` (permission `clipboardWrite`).
  "Вставить очищенным" (в полях ввода) читает буфер через `navigator.clipboard.readText()`
  и вставляет очищенный текст в фокусный элемент — это работает без отдельного
  permission `clipboardRead`, так как вызов происходит в контенте страницы в ответ
  на пользовательский клик по пункту меню. На страницах вне whitelist скрипт
  внедряется точечно через `activeTab`, разрешение не расширяется на весь интернет.
- **Popup.** Textarea → "Очистить" → `normalize()` с текущими настройками → "Копировать".
- **Options.** Чекбоксы включают/выключают каждую группу правил, whitelist редактируется
  (добавление домена запрашивает `chrome.permissions.request` только на этот конкретный домен
  через `optional_host_permissions`, без запроса доступа ко всем сайтам сразу). Настройки хранятся
  в `chrome.storage.sync`.

## Правила замены

Все включены по умолчанию, каждая группа отключается отдельно в настройках.

| # | Группа | Примеры |
|---|--------|---------|
| 1 | Кавычки | `“ ” „ « »` → `"`; `‘ ’ ‚ ‹ ›` → `'` |
| 2 | Тире | `—`/`–` между словами → настраиваемый режим (`" - "` / `"-"` / `", "`); между цифрами всегда `-` (`5–10` → `5-10`) |
| 3 | Многоточие | `…` → `...` |
| 4 | Спецпробелы | `U+00A0`, `U+2002…U+200A`, `U+202F`, `U+205F`, `U+3000` → обычный пробел |
| 5 | Невидимые символы | `U+200B`, `U+2060`, `U+FEFF`, `U+00AD`, `U+200E`, `U+200F` удаляются. `U+200D` (ZWJ) и `U+FE0F` не трогаются никогда — нужны для составных эмодзи |
| 6 | Прочее | `−`(U+2212), `‑`(U+2011) → `-`; `•` → `-`; `→` → `->`; `←` → `<-`; `×` → `x` (только между буквой/цифрой с двух сторон, не в формулах с пробелами); `′` → `'`; `″` → `"` |
| 7 | Схлопывание пробелов | Двойные пробелы, образовавшиеся после замен, схлопываются в один; отступы и переводы строк не трогаются |

**Не трогается:** иврит (`״` U+05F4, `׳` U+05F3, `־` U+05BE, огласовки), содержимое
`<pre>`/`<code>` (DOM-уровень) и URL/email-адреса (на уровне `normalize()` — они
определяются регэкспом и исключаются из всех замен).

## Как добавить своё правило

1. В [src/core/rules.ts](src/core/rules.ts) добавить regex/функцию по аналогии с существующими
   (`replaceQuotes`, `replaceMisc` и т.д.) — чистая функция `string → string`.
2. Подключить её в [src/core/normalize.ts](src/core/normalize.ts) внутри `normalize()`,
   добавив булев флаг в интерфейс `Options` и `defaultOptions`.
3. Добавить чекбокс в [src/options/options.html](src/options/options.html) и
   [src/options/options.ts](src/options/options.ts) (`checkboxIds` + `readOptionsFromForm`).
4. Добавить минимум один тест-кейс в [tests/normalize.test.ts](tests/normalize.test.ts).

## Известные допущения по умолчанию

- Угловые кавычки `« »` трактуются как двойные, одиночные угловые `‹ ›` — как одиночные
  (в ТЗ они упомянуты в обеих группах — вероятно, опечатка).
- `×` заменяется на `x` только когда вплотную примыкает к букве/цифре без пробелов
  (`1920×1080` → `1920x1080`), а `2 × 2` не трогается — это и есть эвристика "не в формулах".
- Сборка — esbuild (без UI-фреймворков, множественные точки входа собираются проще).
